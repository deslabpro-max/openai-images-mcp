# Промт: установка коннектора картинок с помощью ИИ-агента

Не хотите делать шаги руками? Откройте на компьютере ИИ-агента, который
умеет работать в терминале — **Claude Code** или **OpenAI Codex** (CLI,
приложение или расширение для редактора), — и вставьте промт ниже целиком.

Агент сам выполнит всё, что делается в терминале (скачает код, установит
зависимости, развернёт сервер), а шаги в браузере (OpenAI, вход в аккаунты,
подключение коннектора) проведёт с вами по одному клику. Ключ OpenAI вы
вводите сами на странице коннектора — не в чат и не в терминал.

Что нужно заранее: компьютер с Windows, macOS или Linux, бесплатные аккаунты
GitHub и Cloudflare, аккаунт OpenAI.

---

```text
Ты — мой помощник по установке. Установи мне личный коннектор
«Картинки OpenAI → Claude и ChatGPT» строго по инструкции из репозитория
https://github.com/deslabpro-max/openai-images-mcp.
Перед началом прочитай целиком README.md и docs/SETUP.md — это источник
истины; если что-то в этом промте с ними расходится, прав репозиторий.

ПРАВИЛА
- Всё, что делается в терминале, делай сам: git, Node.js/npm, npx wrangler.
  Перед каждой командой одной фразой объясняй, что она делает.
- Шаги, которые возможны только в браузере (кабинет OpenAI, вход в
  аккаунты, Cloudflare Dashboard, подключение коннектора), не выдумывай и
  не делай вслепую: давай мне точные клики по одному шагу и жди, пока я
  напишу «готово». Если у тебя есть управление браузером — можешь нажимать
  сам, но на экранах входа, оплаты и верификации останавливайся и
  передавай управление мне.
- API-ключ OpenAI я НЕ присылаю ни в чат, ни в терминал: я вставлю его
  сам на странице коннектора при подключении. Не проси его.
- Ничего не удаляй и не меняй в моих существующих воркерах Cloudflare,
  кроме того, что создаёшь для этой установки.
- При ошибке сначала сверься с разделом «Частые проблемы» в docs/SETUP.md.
- После каждого шага коротко пиши: что сделано, что дальше.

ПЛАН
1. OpenAI (docs/SETUP.md, часть 1) — веди меня по кликам:
   баланс в Billing; верификация организации (Settings → Organization →
   General → Verify Organization) — объясни, что без неё модели картинок
   недоступны и подтверждение может занять до суток; API-ключ
   (Create new secret key) — напомни сохранить его, он показывается один раз.
   Пока верификация идёт, переходи к следующим шагам.
2. Проверь, что установлены git и Node.js LTS (node -v, git --version).
   Если нет — подскажи, как поставить под мою ОС, и дождись меня.
3. Склонируй репозиторий в удобную папку и выполни npm install.
4. npx wrangler login — откроется браузер, я подтвержу вход в Cloudflare.
5. npx wrangler kv namespace create OAUTH_KV — впиши выданный id в
   wrangler.jsonc (биндинг OAUTH_KV), если wrangler не сделал это сам.
6. npx wrangler deploy. Запомни адрес воркера
   (https://<имя>.<поддомен>.workers.dev), открой его и убедись, что
   показывается страница «Коннектор генерации картинок → Claude».
7. Объясни подключение:
   - Claude: Settings → Connectors → Add custom connector →
     https://<адрес воркера>/mcp → Connect → на странице коннектора я
     вставлю ключ OpenAI → «Подключить»;
   - ChatGPT (Plus/Pro): Settings → Apps & Connectors → Advanced →
     Developer mode → Create → тот же URL, авторизация OAuth.
   Если страница коннектора ответит «модели картинок недоступны» —
   значит, верификация OpenAI ещё не завершена: дождаться и повторить.
8. В конце дай сводку: адрес сервера, что создано (воркер, KV), и фразы
   для проверки в чате: «нарисуй кота-космонавта, quality low»,
   «покажи последние картинки», «сколько я потратил?».
```
