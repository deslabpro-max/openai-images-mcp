[SIZE=5][B]Свой генератор картинок OpenAI (gpt-image-2) в Claude и ChatGPT — бесплатный коннектор[/B][/SIZE]

Инструкция для обычного пользователя без опыта программирования. По шагам поднимем [B]личный бесплатный сервер-коннектор[/B], через который Claude или ChatGPT рисуют и редактируют картинки новейшей моделью OpenAI [B]gpt-image-2[/B]. Время — 20–30 минут плюс ожидание верификации OpenAI, нужен только браузер.

Что получится — в любом чате можно писать:
[LIST]
[*]«Нарисуй обложку для поста про осень в Москве, акварель, без текста»
[*]«Сделай 3 варианта логотипа кофейни, минимализм»
[*]«Замени фон на моём фото на берег моря» — своё фото загружаете по ссылке
[*]«Надень на меня с первого фото куртку со второго»
[*]«Сделай стикер с котом и прозрачным фоном»
[*]«Сколько я потратил на картинки в этом месяце?»
[/LIST]

[SPOILER=Как это работает и почему выгодно]
Вы разворачиваете на бесплатном тарифе Cloudflare [B]свой личный сервер[/B] (протокол MCP — его понимают Claude и ChatGPT). Он принимает задания из чата, отправляет их в OpenAI с [B]вашим[/B] API-ключом и возвращает ссылку на готовую картинку.
[LIST]
[*]платите только OpenAI и только за нарисованное: обычная картинка в среднем качестве — около [B]$0.04[/B], без подписок и наценок;
[*]ключ OpenAI вводите один раз на странице коннектора — в чат он не попадает, хранится зашифрованным в вашем Cloudflare;
[*]картинки хранятся 30 дней по случайным ссылкам;
[*]код открыт (MIT): [URL=https://github.com/deslabpro-max/openai-images-mcp]github.com/deslabpro-max/openai-images-mcp[/URL]
[/LIST]
[/SPOILER]

[B]Что понадобится[/B]
[LIST=1]
[*]Аккаунт OpenAI (platform.openai.com) с пополненным балансом (хватит $5) и способ оплаты, который OpenAI принимает — OpenAI работает не во всех странах
[*]Документ для верификации организации в OpenAI — без неё модели картинок недоступны

[SIZE=4][B]Часть 1. OpenAI: баланс, верификация, ключ (10 минут + ожидание)[/B][/SIZE]
[B]1.1. Баланс[/B]
[LIST=1]
[*]platform.openai.com (кабинет разработчика, не chatgpt.com) → войти
[*]Шестерёнка [B]Settings → Billing → Add payment details[/B] → карта → [B]Add to credit balance[/B] → $5–10
[/LIST]
[B]1.2. Верификация организации — обязательно[/B]
[LIST=1]
[*][B]Settings → Organization → General → Verify Organization[/B]
[*]Фото документа и селфи через сервис Persona
[*]Подтверждение — от нескольких минут до суток. Пока его нет, коннектор скажет «Ключ рабочий, но модели картинок недоступны»
[/LIST]
[B]1.3. API-ключ[/B]
[LIST=1]
[*][B]Settings → API keys → Create new secret key[/B], имя любое, Permissions — All
[*]Ключ sk-proj-… покажут [B]один раз[/B] — сохраните в заметки. Никому не отправляйте и не вставляйте в чат
[/LIST]
Совет: в [B]Settings → Limits[/B] задайте месячный лимит расходов — страховка от перерасхода.

[SIZE=4][B]Часть 2. Сервер на Cloudflare (5 минут)[/B][/SIZE]
[LIST=1]
[*]Откройте репозиторий: [URL=https://github.com/deslabpro-max/openai-images-mcp]github.com/deslabpro-max/openai-images-mcp[/URL]
[*]Нажмите в README кнопку [B]Deploy to Cloudflare[/B]
[*]Войдите в Cloudflare (или зарегистрируйтесь) и разрешите доступ к GitHub
[*]Ничего не меняйте — жмите [B]Create and deploy[/B]. Ключей и секретов задавать не нужно
[*]Через минуту-две получите адрес [CODE]https://imagegen-connector.ВАШ-ПОДДОМЕН.workers.dev[/CODE] (если задали своё имя воркера — в адресе будет оно). Откройте в браузере: страница «Коннектор генерации картинок → Claude» = сервер работает
[/LIST]

[SIZE=4][B]Часть 3а. Подключение к Claude[/B][/SIZE]
[LIST=1]
[*]claude.ai → Settings → [B]Connectors[/B] → [B]Add custom connector[/B]
[*]URL: [CODE]https://imagegen-connector.ВАШ-ПОДДОМЕН.workers.dev/mcp[/CODE]
[*]Add → [B]Connect[/B] → откроется страница коннектора → вставьте ключ sk-… → [B]Подключить[/B] (ключ проверяется бесплатным запросом)
[*]Работает во всех чатах: браузер, телефон, десктоп. Проверка: «нарисуй кота-космонавта, medium»
[/LIST]

[SIZE=4][B]Часть 3б. Подключение к ChatGPT (Plus/Pro)[/B][/SIZE]
[LIST=1]
[*]Settings → [B]Apps & Connectors[/B] → Advanced settings → включить [B]Developer mode[/B]
[*]Apps & Connectors → [B]Create[/B] → имя «Картинки», URL тот же с /mcp, Authentication: [B]OAuth[/B]
[*]Страница коннектора → вставьте ключ → Подключить. В чате — меню «+»
[/LIST]

[SPOILER=Лень делать руками? Пусть всё сделает ИИ-агент (Claude Code / Codex)]
Откройте на компьютере [B]Claude Code[/B] или [B]OpenAI Codex[/B] и вставьте промт из файла [URL=https://github.com/deslabpro-max/openai-images-mcp/blob/main/docs/AGENT_PROMPT.md]docs/AGENT_PROMPT.md[/URL]. Агент сам выполнит терминальную часть, а шаги в браузере (OpenAI, подключение) проведёт по одному клику. Ключ OpenAI вводите сами на странице коннектора.
[/SPOILER]

[SPOILER=Как пользоваться: качество, своё фото, маска, расходы]
[B]Качество выбираете вы:[/B] low ≈ $0.01–0.02 (черновики), medium ≈ $0.04–0.06 (основная работа), high ≈ $0.17–0.25 (финал).
[B]Своё фото:[/B] прикрепить в чат не выйдет — инструменты коннектора принимают только текст. Скажите «хочу отредактировать своё фото» → ассистент даст ссылку → откройте (можно с телефона), выберите фото → «Загрузить» → напишите «загрузил». Можно несколько фото сразу — для совмещения.
[B]Точечная правка:[/B] «измени только фон» → ссылка на рисовалку маски → закрасьте зону → остальное не изменится.
[B]Расходы:[/B] каждый ответ содержит точную стоимость, «сколько я потратил?» — сумма за месяц.
[/SPOILER]

[SPOILER=Частые проблемы и решения]
[LIST]
[*][B]«Ключ рабочий, но модели картинок недоступны»[/B] — не пройдена верификация организации или нет баланса. Дождитесь подтверждения и переподключите коннектор
[*][B]«OpenAI не принял API-ключ (401)»[/B] — ключ удалён или скопирован не полностью: создайте новый и переподключите
[*][B]«лимит запросов или исчерпан баланс»[/B] — пополните Billing или проверьте Settings → Limits
[*][B]Чат ответил «таймаут», а картинки нет[/B] — high рисуется дольше минуты, чат прерывает ожидание. Картинка всё равно сохраняется: «покажи последние картинки»
[*][B]«Картинка не найдена или истёк срок»[/B] — хранятся 30 дней, скачивайте нужное
[*][B]Ассистент говорит «не могу загрузить фото»[/B] — попросите ссылку для загрузки
[*][B]В ChatGPT нет кнопки Create[/B] — не включён Developer mode или план Free
[/LIST]
[/SPOILER]

[B]Безопасность:[/B] ключ хранится только в вашем Cloudflare в зашифрованном виде; картинки открываются по случайной ссылке без входа — ненужное удаляйте; посторонний, узнавший адрес сервера, подключится только со своим ключом и ваш баланс не тратит.

[B]Обновления:[/B] кнопка Deploy создала вашу копию репозитория с автосборкой — новые версии подтягиваются кнопкой Sync fork на GitHub.
