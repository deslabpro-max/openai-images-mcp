# Свой генератор картинок OpenAI в Claude и ChatGPT — подробная инструкция

Инструкция для обычного пользователя без опыта программирования. По шагам
поднимем **личный бесплатный сервер-коннектор**, через который Claude или
ChatGPT рисуют и редактируют картинки новейшей моделью OpenAI
**gpt-image-2**. Время — 20–30 минут плюс ожидание верификации OpenAI
(обычно от часа до суток), из инструментов — только браузер.

> **Не хотите делать шаги руками?** Отдайте установку ИИ-агенту (Claude Code
> или Codex) — промт в [AGENT_PROMPT.md](AGENT_PROMPT.md).

Что получится — в любом чате можно писать:

- «Нарисуй обложку для поста про осень в Москве, акварель, без текста»
- «Сделай 3 варианта логотипа кофейни, минимализм»
- «Замени фон на моём фото на берег моря» — загружаете своё фото по ссылке
- «Надень на меня с первого фото куртку со второго»
- «Сделай стикер с котом и прозрачным фоном»
- «Сколько я потратил на картинки в этом месяце?»

## Как это работает и почему это выгодно

Вы разворачиваете на бесплатном тарифе Cloudflare **свой личный сервер**
(протокол MCP — его понимают Claude и ChatGPT). Он принимает задания из
чата, отправляет их в OpenAI с **вашим** API-ключом и возвращает ссылку на
готовую картинку.

- Платите только OpenAI и только за то, что нарисовали: обычная картинка
  в среднем качестве — около **$0.04**. Без подписок и наценок.
- Ключ OpenAI вводите один раз на странице коннектора — в чат он не
  попадает, хранится зашифрованным в вашем Cloudflare.
- Картинки хранятся 30 дней по случайным ссылкам — скачать, переслать,
  опубликовать.

## Что понадобится

1. Аккаунт [OpenAI](https://platform.openai.com) с пополненным балансом
   (хватит $5) и способ оплаты, который OpenAI принимает. OpenAI работает
   не во всех странах.
2. Документ для **верификации организации** в OpenAI — без неё модели
   картинок недоступны (подробно в Части 1).
3. Бесплатный аккаунт [GitHub](https://github.com/signup).
4. Бесплатный аккаунт [Cloudflare](https://dash.cloudflare.com/sign-up).
5. Claude (кастомные коннекторы доступны на платных планах) или ChatGPT
   Plus/Pro (нужен Developer mode).

## Часть 1. OpenAI: баланс, верификация и ключ (10 минут + ожидание)

### 1.1. Баланс

1. Откройте [platform.openai.com](https://platform.openai.com) и войдите
   (это кабинет для разработчиков, не путать с chatgpt.com — аккаунт
   может быть тот же).
2. Справа сверху шестерёнка **Settings → Billing** → **Add payment
   details** → привяжите карту → **Add to credit balance** → $5–10.

### 1.2. Верификация организации — обязательно

Модели картинок (gpt-image-2, gpt-image-1) OpenAI открывает только
**верифицированным организациям**.

1. **Settings → Organization → General** → кнопка **Verify Organization**.
2. Пройдите проверку: фото документа и селфи через сервис Persona.
3. Подтверждение приходит от нескольких минут до суток. Пока его нет,
   коннектор при подключении скажет: «Ключ рабочий, но модели картинок
   недоступны».

### 1.3. API-ключ

1. **Settings → API keys** (или [platform.openai.com/api-keys](https://platform.openai.com/api-keys))
   → **Create new secret key**.
2. Имя — любое, например `claude-images`; Permissions — **All**.
3. **Create secret key** → ключ вида `sk-proj-…` покажут **один раз** —
   скопируйте в заметки. Никому его не отправляйте и не вставляйте в чат.

> Совет: в **Settings → Limits** можно задать месячный лимит расходов —
> страховка от случайного перерасхода.

## Часть 2. Сервер на Cloudflare (5 минут)

1. Откройте репозиторий:
   **github.com/deslabpro-max/openai-images-mcp**
2. Нажмите в описании кнопку **Deploy to Cloudflare**.
3. Войдите в Cloudflare (или зарегистрируйтесь) и разрешите доступ к GitHub.
4. На странице настройки ничего менять не обязательно — жмите
   **Create and deploy**. Cloudflare сам скопирует код в ваш GitHub,
   создаст хранилище и запустит сервер. Ключей и секретов задавать
   **не нужно**.
5. Через минуту-две появится адрес сервера:

   ```
   https://imagegen-connector.ВАШ-ПОДДОМЕН.workers.dev
   ```

   (если задали другое имя воркера — в адресе и в примерах ниже будет оно).
   Откройте адрес в браузере: страница «Коннектор генерации картинок →
   Claude» означает, что сервер работает.

## Часть 3а. Подключаем к Claude

1. [claude.ai](https://claude.ai) → **Settings → Connectors**
   (Настройки → Коннекторы).
2. **Add custom connector** → в поле URL:

   ```
   https://imagegen-connector.ВАШ-ПОДДОМЕН.workers.dev/mcp
   ```

3. **Add**, затем **Connect** — откроется страница коннектора с полем для
   ключа. Вставьте ключ `sk-…` из шага 1.3 → **Подключить**. Коннектор
   проверит ключ бесплатным запросом.
4. Готово: работает во всех чатах Claude — в браузере, на телефоне,
   в десктоп-приложении. Проверка: «нарисуй кота-космонавта, medium».

## Часть 3б. Подключаем к ChatGPT (Plus/Pro)

1. ChatGPT → аватарка → **Settings** → **Apps & Connectors** → внизу
   **Advanced settings** → включите **Developer mode**.
2. Вернитесь в **Apps & Connectors** → **Create**.
3. Имя `Картинки`, MCP Server URL — тот же адрес с `/mcp`,
   Authentication: **OAuth** → создать.
4. Откроется страница коннектора → вставьте ключ OpenAI → **Подключить**.
5. В чате коннектор подключается через меню «+».

Интерфейс OpenAI часто меняется — ориентируйтесь на слова Developer mode /
Connectors / MCP.

## Как пользоваться

**Качество выбираете вы** — коннектор всегда спросит, если не указали:

| Качество | ≈ за картинку | Для чего |
|---|---|---|
| low | $0.01–0.02 | черновики, поиск идеи |
| medium | $0.04–0.06 | основная работа |
| high | $0.17–0.25 | финал |

**Своё фото.** Прикрепить фото в чат и попросить «отредактируй» не
выйдет — инструменты коннектора принимают только текст. Поэтому:
скажите «хочу отредактировать своё фото» → ассистент даст ссылку →
откройте её (можно с телефона), выберите фото → «Загрузить» → напишите
«загрузил». Можно несколько фото сразу — для совмещения («куртку со
второго фото — на человека с первого»).

**Точечная правка.** «Измени только фон» → ассистент даст ссылку на
рисовалку маски → закрасьте зону → всё вне маски не изменится.

**Расходы.** Каждый ответ содержит точную стоимость вызова; «сколько я
потратил?» покажет сумму за месяц.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| «Ключ рабочий, но модели картинок недоступны» | Не пройдена верификация организации (шаг 1.2) или нет баланса. Дождитесь подтверждения и переподключите коннектор |
| «OpenAI не принял API-ключ (401)» | Ключ удалён или скопирован не полностью. Создайте новый и переподключите коннектор |
| «лимит запросов или исчерпан баланс» | Пополните баланс в Billing или проверьте лимиты в Settings → Limits |
| Чат ответил «таймаут», а картинки нет | Качество high рисуется дольше минуты, и чат прерывает ожидание. Картинка всё равно сохраняется — попросите «покажи последние картинки» |
| «Картинка не найдена или истёк срок» | Картинки хранятся 30 дней — скачивайте нужное |
| Ассистент говорит «не могу загрузить фото» | Попросите его дать ссылку для загрузки (`get_upload_link`) |
| В ChatGPT нет кнопки Create | Не включён Developer mode или план Free |

## Безопасность

- Ключ OpenAI хранится только в вашем Cloudflare, в зашифрованном виде.
  Отозвать — удалить ключ на platform.openai.com.
- Картинки открываются по случайной ссылке без входа: у кого ссылка — тот
  увидит. Ненужное удаляйте («удали картинку …»).
- Посторонний, узнавший адрес сервера, может подключиться только **со
  своим** ключом — ваш баланс он не тратит.

## Обновления

Кнопка Deploy создала вашу копию репозитория с автосборкой. Новые версии
из оригинала подтягиваются кнопкой **Sync fork** на GitHub — Cloudflare
пересоберёт сам.
